Diseño experimental: 140 modelos con validación anidada#

El pipeline combinatorio#

Cada modelo base se combina con cada técnica de balanceo (solo en clasificación) y cada combinación se ajusta con cada método de optimización. El total es un producto, no una suma:

\[\underbrace{7}_{\text{modelos}} \times \underbrace{4}_{\text{balanceo}} \times \underbrace{4}_{\text{optimizadores}} = 112 \text{ (clasificación)}, \qquad 7 \times 4 = 28 \text{ (regresión)}, \qquad 112 + 28 = 140.\]

Como cada combinación se evalúa en 3 pliegues externos, el experimento tiene 420 tareas de optimización, más 140 reajustes finales. Todo se programa con bucles sobre funciones parametrizadas (modelo → balanceo → optimizador) y se ejecuta en paralelo con joblib (10 procesos).

class_weight balanced

Cada error de la clase \(c\) pesa \(n/(2n_c)\)

Parámetro nativo; sample_weight para Naive Bayes y XGBoost; corrección por la probabilidad a priori en KNN

KNN no acepta pesos de muestra. Su equivalente es dividir la proporción de vecinos de cada clase por su prevalencia y renormalizar, \(\tilde p_c \propto p_c / \pi_c\): la regla de Bayes con clases equiprobables.

def construir(tarea, nombre, params, balanceo="Sin balanceo", semilla=42):
    """Construye el Pipeline completo de una combinación (preprocesamiento + balanceo + modelo).

    Parameters
    ----------
    tarea : {"clf", "reg"}
        Clasificación o regresión.
    nombre : str
        Modelo (uno de MODELOS_CLF o MODELOS_REG).
    params : dict
        Hiperparámetros del modelo.
    balanceo : str
        Estrategia de balanceo (solo clasificación).
    semilla : int
        Semilla para todos los componentes aleatorios.

    Returns
    -------
    imblearn.pipeline.Pipeline
        Pipeline sin ajustar.
    """
    pasos = [("imputer", SimpleImputer(strategy="median")), ("scaler", StandardScaler())]  # Preprocesamiento (se ajusta en cada pliegue)
    if tarea == "clf":  # Clasificación
        if balanceo == "SMOTE":  # Interpolación entre vecinos de la clase minoritaria
            pasos.append(("sampler", SMOTE(k_neighbors=5, random_state=semilla)))
        elif balanceo == "ADASYN":  # Más muestras sintéticas donde la clase minoritaria es más difícil
            pasos.append(("sampler", ADASYN(n_neighbors=5, random_state=semilla)))
        pasos.append(("modelo", _clasificador(nombre, params, balanceo == "class_weight balanced", semilla)))  # Modelo
    else:  # Regresión (sin balanceo)
        pasos.append(("modelo", _regresor(nombre, params, semilla)))  # Modelo
    return Pipeline(pasos)  # Pipeline de imbalanced-learn

Validación cruzada anidada#

Reportar la métrica del mejor modelo sobre el mismo esquema que lo eligió es optimista (sesgo de selección). Por eso hay dos bucles, ambos por años y con purga de 4 semanas (el objetivo de la fila \(t\) está en \(t+4\)):

  • Bucle externo (3 pliegues): cada año \(a \in \{2019, 2020, 2021\}\) se evalúa con un modelo entrenado solo con los años anteriores. Es la métrica que se reporta (media ± desviación de los 3 pliegues).

  • Bucle interno (2 pliegues): dentro del entrenamiento de cada pliegue externo, los dos últimos años validan; el optimizador solo ve el promedio de estos pliegues.

¿Por qué 3 y 2? El tiempo no se puede barajar: los pliegues son años completos, y un pliegue externo necesita al menos 4 años previos (2 para entrenar y 2 para validar dentro). 2019–2021 cubre un año epidémico (2019), uno de pandemia (2020) y uno de baja transmisión (2021), así que la desviación entre pliegues refleja regímenes reales. Para que las 420 tareas quepan en el presupuesto, el entrenamiento externo se submuestrea a 20 000 filas estratificadas por año y clase; el año evaluado se usa completo.

Métrica de validación#

El criterio que maximizan los cuatro optimizadores es el AUC-PR (precisión promedio) en clasificación y el −RMSE en regresión. Un brote no anticipado (falso negativo) cuesta más que una falsa alarma, pero la capacidad de respuesta de una secretaría también es limitada: el AUC-PR resume el compromiso precisión–recall en todos los umbrales y, a diferencia del AUC-ROC, se concentra en la clase brote y no se infla con los verdaderos negativos (90 % de las filas). El umbral concreto se elige después maximizando F1 en 2022; con él se reportan Accuracy, Precision, Recall y F1.

Los cuatro optimizadores (y uno adicional)#

Método

Cómo propone el siguiente candidato

Exploración / explotación

Grid Search

Malla regular: la mayor que cabe en 20 evaluaciones (las dimensiones sin niveles quedan en el centro del rango)

Solo exploración, fija de antemano; sufre con muchas dimensiones

Random Search

Muestreo independiente, uniforme o log-uniforme

Solo exploración; cubre mejor las dimensiones importantes que la malla (Bergstra y Bengio, 2012)

Bayesiana (Optuna, TPE)

Modelo sustituto Tree-structured Parzen Estimator: estima \(l(x) = p(x \mid y \text{ bueno})\) y \(g(x) = p(x \mid y \text{ malo})\) con el cuantil γ de los mejores resultados, y propone el candidato que maximiza \(l(x)/g(x)\)

La razón \(l/g\) es equivalente a maximizar la Mejora Esperada (EI); 5 evaluaciones aleatorias iniciales exploran y después explota, con exploración residual por los 24 candidatos muestreados de \(l(x)\)

Genética (DEAP)

Población de 6 configuraciones codificadas en \([0, 1]^d\); selección por torneo (3), cruce de mezcla (α = 0,5, p = 0,7), mutación gaussiana (σ = 0,15, p = 0,3); estrategia (μ + λ) con elitismo

El cruce explota combinaciones de buenos padres; la mutación y los inmigrantes mantienen la diversidad, que se registra por generación

Successive Halving (complementario)

27 candidatos con 1/9 de las filas, los mejores 9 con 1/3 y los mejores 3 con todas (factor 3)

Gasta poco en las configuraciones malas y reasigna el presupuesto a las competitivas

Sin fuga de datos en ningún método. Optuna y DEAP no integran validación cruzada: la función objetivo implementada a mano ajusta el Pipeline completo (imputación, estandarización, remuestreo y modelo) dentro de cada pliegue interno, con los datos de entrenamiento del pliegue.

def bayesiana(espacio, objetivo, presupuesto, semilla=42, arranque=5):
    """Optimización bayesiana con Optuna: modelo sustituto TPE (Tree-structured Parzen Estimator).

    TPE modela p(x | y bueno) = l(x) y p(x | y malo) = g(x) con estimadores de densidad de Parzen y propone el candidato
    que maximiza l(x)/g(x), que es equivalente a maximizar la Mejora Esperada (EI). Las ``arranque`` primeras
    evaluaciones son aleatorias (exploración); después TPE explota las regiones prometedoras.
    """
    historial, t0 = [], time.perf_counter()  # Historial y cronómetro

    def f(trial):  # Función objetivo de Optuna
        p = {}  # Hiperparámetros sugeridos
        for k, spec in espacio.items():  # Cada dimensión
            if spec[0] == "cat":  # Categórica
                p[k] = trial.suggest_categorical(k, spec[1])
            elif spec[0] == "int":  # Entera
                p[k] = trial.suggest_int(k, spec[1], spec[2], log=spec[3])
            else:  # Real
                p[k] = trial.suggest_float(k, spec[1], spec[2], log=spec[3])
        v = objetivo(p)  # Evalúa
        _registrar(historial, p, v, t0)  # Registra
        return v  # Optuna maximiza

    muestreador = optuna.samplers.TPESampler(seed=semilla, n_startup_trials=arranque, multivariate=True)  # TPE multivariado
    optuna.create_study(direction="maximize", sampler=muestreador).optimize(f, n_trials=presupuesto)  # Optimiza
    return historial  # Historial

def genetica(espacio, objetivo, presupuesto, semilla=42, poblacion=6, p_cruce=0.7, p_mutacion=0.3, torneo=3):
    """Algoritmo genético (DEAP) con codificación real en [0, 1]^d y estrategia (μ + λ).

    * Selección: torneo de tamaño ``torneo`` (presión selectiva moderada, robusta a la escala de la aptitud).
    * Cruce: mezcla (blend, α = 0,5) con probabilidad ``p_cruce``: explora entre y alrededor de los padres.
    * Mutación: gaussiana (σ = 0,15, probabilidad por gen 0,3) con probabilidad ``p_mutacion``: mantiene diversidad.
    * Elitismo: (μ + λ) conserva los μ mejores entre padres e hijos, así que el mejor nunca se pierde.
    * Caché: una configuración ya evaluada no vuelve a gastar presupuesto.

    Returns
    -------
    historial : list of dict
        Evaluaciones (solo las nuevas).
    diversidad : list of float
        Distancia media entre individuos de cada generación (normalizada por √d): si cae a ~0, hay convergencia prematura.
    """
    random.seed(semilla)  # DEAP usa el módulo random: se siembra una vez (cada tarea corre en su propio proceso)
    rnd = random  # Mismo generador para los operadores y las decisiones
    d = len(espacio)  # Dimensión del genotipo
    tb = base.Toolbox()  # Caja de herramientas de DEAP
    tb.register("individuo", lambda: creator.Individuo([rnd.random() for _ in range(d)]))  # Individuo aleatorio
    historial, cache, t0 = [], {}, time.perf_counter()  # Historial, caché y cronómetro

    def aptitud(ind):  # Evalúa un individuo (con caché)
        p = decodificar(espacio, ind)  # Fenotipo
        k = _clave(p)  # Clave
        if k not in cache:  # Nueva configuración
            cache[k] = objetivo(p)  # Evalúa
            _registrar(historial, p, cache[k], t0)  # Registra
        return (cache[k],)  # Tupla de aptitud

    def diversidad_de(pob):  # Distancia media entre pares de individuos
        G = np.array(pob)  # Matriz de genes
        dist = [np.linalg.norm(G[i] - G[j]) for i in range(len(G)) for j in range(i + 1, len(G))]  # Distancias
        return float(np.mean(dist) / math.sqrt(d))  # Normalizada

    pob = [tb.individuo() for _ in range(poblacion)]  # Población inicial
    for ind in pob:  # Evalúa
        ind.fitness.values = aptitud(ind)
    diversidad = [diversidad_de(pob)]  # Diversidad inicial
    while len(historial) < presupuesto:  # Generaciones hasta agotar el presupuesto
        hijos = []  # Descendencia
        while len(hijos) < poblacion:  # λ = μ hijos
            a, b = [creator.Individuo(x) for x in tools.selTournament(pob, 2, tournsize=torneo)]  # Dos padres por torneo
            if rnd.random() < p_cruce:  # Cruce
                tools.cxBlend(a, b, alpha=0.5)  # Mezcla
            for h in (a, b):  # Mutación de cada hijo
                if rnd.random() < p_mutacion:  # ¿Muta?
                    tools.mutGaussian(h, mu=0, sigma=0.15, indpb=0.3)  # Ruido gaussiano
                h[:] = [min(max(g, 0.0), 1.0) for g in h]  # Recorta a [0, 1]
                del h.fitness.values  # Invalida la aptitud
                hijos.append(h)  # Agrega
        antes = len(historial)  # Evaluaciones antes de la generación
        for h in hijos:  # Evalúa los hijos
            h.fitness.values = aptitud(h)
            if len(historial) >= presupuesto:  # Presupuesto agotado
                break  # Termina
        hijos = [h for h in hijos if h.fitness.valid]  # Hijos evaluados
        pob = tools.selBest(pob + hijos, poblacion)  # (μ + λ): elitismo
        diversidad.append(diversidad_de(pob))  # Diversidad de la generación
        if len(historial) == antes:  # Solo configuraciones repetidas: población convergida
            pob[-1] = tb.individuo()  # Inmigrante aleatorio para no estancarse
            pob[-1].fitness.values = aptitud(pob[-1])  # Evalúa
    return historial, diversidad  # Historial y diversidad

def ejecutar_tarea(tarea, modelo, balanceo, metodo, anio, semilla=c3.SEMILLA, presupuesto=c3.PRESUPUESTO, guardar=True, semilla_optimizador=None):
    """Ejecuta un pliegue externo de la validación anidada para una combinación.

    Parameters
    ----------
    tarea : {"clf", "reg"}
        Clasificación o regresión.
    modelo, balanceo, metodo : str
        Combinación (balanceo = "—" en regresión).
    anio : int
        Año del pliegue externo.
    semilla : int
        Semilla del optimizador, del muestreo y de los modelos.
    presupuesto : int
        Evaluaciones de hiperparámetros.
    guardar : bool
        Si True, guarda el resultado en resultados/tareas.
    semilla_optimizador : int, optional
        Semilla solo del optimizador (los datos y los modelos conservan ``semilla``); sirve para aislar la variabilidad del
        método de búsqueda en el estudio de estabilidad.

    Returns
    -------
    dict
        Registro con los mejores hiperparámetros, las métricas del bucle externo, los tiempos y el historial.
    """
    c3.fijar_semilla(semilla)  # Semilla global en este proceso
    tr, _, _ = datos()  # Entrenamiento 2015–2021
    y_col = dd.Y_CLF if tarea == "clf" else dd.Y_REG  # Objetivo
    espacio = (mo.ESPACIOS_CLF if tarea == "clf" else mo.ESPACIOS_REG)[modelo]  # Espacio de búsqueda
    ent_full, ev = dd.pliegue_externo(tr, anio)  # Pliegue externo
    ent = dd.submuestra(ent_full, c3.N_EXTERNO, semilla)  # Submuestra estratificada del entrenamiento externo
    X, y = ent[dd.X_COLS].to_numpy(), ent[y_col].to_numpy()  # Matrices
    internos = dd.pliegues_internos(ent)  # Pliegues internos hacia adelante
    rng = np.random.default_rng(semilla)  # Para las fidelidades parciales
    errores = []  # Configuraciones que fallaron

    def objetivo(p, fidelidad=1.0):  # Promedio de los pliegues internos (lo único que ve el optimizador)
        puntajes = []  # Por pliegue interno
        for i_tr, i_va in internos:  # Cada pliegue interno
            if fidelidad < 1.0:  # Multi-fidelidad: fracción de las filas de entrenamiento
                i_tr = np.sort(rng.choice(i_tr, max(200, int(fidelidad * len(i_tr))), replace=False))  # Submuestra
            try:  # Algunas combinaciones pueden fallar (por ejemplo, ADASYN sin vecinos minoritarios)
                m = mo.construir(tarea, modelo, p, balanceo, semilla).fit(X[i_tr], y[i_tr])  # Pipeline completo ajustado en el pliegue
                s = mo.puntaje(m, X[i_va]) if tarea == "clf" else m.predict(X[i_va])  # Predicción en la validación interna
                puntajes.append(average_precision_score(y[i_va], s) if tarea == "clf" else -np.sqrt(mean_squared_error(y[i_va], s)))  # AUC-PR o −RMSE
            except Exception as e:  # Falla registrada
                errores.append(repr(e))  # Guarda el motivo
                puntajes.append(0.0 if tarea == "clf" else -10.0)  # Peor puntaje posible
        return float(np.mean(puntajes))  # Promedio

    s_opt = semilla if semilla_optimizador is None else semilla_optimizador  # Semilla del optimizador
    t0 = time.perf_counter()  # Cronómetro total
    diversidad = None  # Solo para el genético
    if metodo == "Genética (DEAP)":  # Devuelve también la diversidad
        historial, diversidad = op.genetica(espacio, objetivo, presupuesto, s_opt)
    elif metodo == "Successive Halving":  # Multi-fidelidad (análisis complementario de eficiencia)
        historial = op.halving(espacio, objetivo, semilla=s_opt)
    else:  # Los demás
        historial = op.METODOS[metodo](espacio, objetivo, presupuesto, s_opt)
    t_opt = time.perf_counter() - t0  # Tiempo de optimización
    completas = [h for h in historial if h["fidelidad"] >= 1.0] or historial  # Solo evaluaciones con fidelidad completa
    mejor = max(completas, key=lambda h: h["valor"])  # Mejor configuración según el bucle interno
    t1 = time.perf_counter()  # Cronómetro del reajuste
    m = mo.construir(tarea, modelo, mejor["params"], balanceo, semilla).fit(X, y)  # Reajuste con todo el entrenamiento externo
    t_fit = time.perf_counter() - t1  # Tiempo de ajuste
    t2 = time.perf_counter()  # Cronómetro de predicción
    Xe, ye = ev[dd.X_COLS].to_numpy(), ev[y_col].to_numpy()  # Año evaluado completo
    s = mo.puntaje(m, Xe) if tarea == "clf" else m.predict(Xe)  # Predicción
    t_pred = time.perf_counter() - t2  # Tiempo de inferencia
    probabilistico = tarea == "clf" and modelo != "SVM"  # La SVM da márgenes, no probabilidades
    registro = {"tarea": tarea, "modelo": modelo, "balanceo": balanceo, "optimizador": metodo, "anio_externo": anio, "semilla": semilla, "semilla_optimizador": s_opt,
                "mejores_params": mejor["params"], "valor_interno": mejor["valor"], **_metricas(tarea, ye, s, probabilistico),
                "evaluaciones": len(historial), "segundos_optimizacion": t_opt, "segundos_por_evaluacion": t_opt / len(historial),
                "segundos_ajuste": t_fit, "segundos_prediccion_1000": 1000 * t_pred / len(ye), "n_entrenamiento": len(ent),
                "n_evaluacion": len(ye), "errores": len(errores), "historial": historial, "diversidad": diversidad}
    if guardar:  # Guarda en disco
        TAREAS.mkdir(parents=True, exist_ok=True)  # Carpeta
        with open(TAREAS / _nombre(tarea, modelo, balanceo, metodo, anio), "wb") as f:  # Archivo de la tarea
            pickle.dump(registro, f)  # Guarda
    return registro  # Registro

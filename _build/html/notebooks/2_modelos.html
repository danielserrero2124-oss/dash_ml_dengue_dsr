4. Entrenamiento y resultados de los cinco modelos#

Este cuaderno ejecuta el flujo completo de src/entrenamiento.py: los cuatro modelos recomendados con Pipeline + GridSearchCV y validación temporal hacia adelante, y el modelo original HetDS en línea. Al final guarda los artefactos que usa el dashboard.

4.2. Ejecución del entrenamiento#

La celda siguiente entrena todo (varios minutos: GradientBoosting es el más costoso).

t0 = time.time()  # Inicio

joblib.dump(art, cf.RUTA_ARTEFACTOS, compress=3)  # Artefactos para el dashboard
joblib.dump(hetds, cf.RAIZ / "dashboard" / "hetds.joblib", compress=3)  # Modelo original para el simulador

6. El dashboard#

6.1. Cómo ejecutarlo#

Desde la carpeta raíz del proyecto, con el entorno de Python 3.9:

.venv\Scripts\python -m src.entrenamiento   # entrena los cinco modelos (o ejecutar notebooks/2_modelos.ipynb)
.venv\Scripts\python -m src.pruebas         # pruebas de significancia, ablación y tiempos
.venv\Scripts\python -m dashboard.app       # abre http://localhost:8050

6.4. Diseño visual#

El tema oscuro usa un acento rojo «dengue» para la marca y una paleta categórica validada para los datos: azul para «sin brote», rojo para «brote» y un color fijo por modelo (magenta para HetDS). Las imágenes se usan como fondo de los encabezados de cada sección, con un degradado oscuro que conserva la legibilidad.
